# Smart Employee Onboarding & Offboarding System

## Project Description

A ServiceNow application that automates employee onboarding and offboarding workflows using Flow Designer and App Engine Studio.

## Features

- Employee Onboarding Requests
- Employee Offboarding Requests
- Automated Task Assignment
- Workflow Automation
- Employee Lifecycle Dashboard

## Technologies

- ServiceNow
- App Engine Studio
- Flow Designer
- Dashboards
