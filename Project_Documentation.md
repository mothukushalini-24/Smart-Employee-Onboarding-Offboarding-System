# Smart Employee Onboarding & Offboarding System

A ServiceNow application developed using App Engine Studio and Flow Designer to automate employee onboarding and offboarding processes.

## Features

* Employee Onboarding Management
* Employee Offboarding Management
* Automated Task Assignment
* Workflow Automation
* Employee Lifecycle Dashboard

## Technologies

* ServiceNow
* App Engine Studio
* Flow Designer
* Dashboards
